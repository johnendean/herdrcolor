# A Go binary, fetched at install, replaces bare Python

herdrcolor used to run as a bare system `python3` with `PYTHONPATH` set. It had no install step, but that only worked where Python 3.11 or later was already on the path. That is rarely true on Windows, where `python3` is often just the Microsoft Store stub. CPython on Windows also has no `AF_UNIX`, and Herdr's Windows transport is a named pipe anyway. To make `herdr plugin install johnendean/herdrcolor` the whole install on every platform, herdrcolor is now a static Go binary.

`herdr plugin install` is a `git clone` followed by `[[build]]`, and Herdr does not install toolchains. So `[[build]]` runs a small committed fetch script, `bin/fetch.sh` or `bin/fetch.ps1`. The script downloads the release asset whose tag matches the manifest `version`, and checks it against the SHA-256 sums in `checksums.txt` at that commit. Builds are reproducible, so those sums can be committed before the tag exists. CI rebuilds from the tag and refuses to publish if any hash differs.

The binary talks to Herdr through the `herdr` CLI (found through `HERDR_BIN_PATH`) rather than the socket. That gives one transport on every platform and no named-pipe code, at the cost of a short-lived process per request.

## Considered Options

- **Keep Python and require 3.11 on PATH.** Least work, but it fails the goal on a fresh Windows machine.
- **Python through `uv`.** This only swaps "install Python" for "install uv".
- **Commit prebuilt binaries.** Works offline, but every release would add about 15 MB to git history permanently.
- **`go build` at install.** Needs Go installed, which is not trivial for a user.

## Consequences

- Changes on `main` reach users only when a release is tagged, because `main`'s manifest always names a published release.
- A linked checkout (`herdr plugin link`) prefers a locally built binary, so development needs Go and no release.
- Colour assignment must stay identical to the Python version. A checked-in table of colour assignments generated by the Python code guards that.
